# GameZone

Portal de games responsivo criado com HTML, CSS e JavaScript puro.

## Recursos

- Interface responsiva para desktop e celular
- Catálogo de jogos com categorias
- Busca instantânea
- Mini-game de reflexos jogável no navegador
- Modal de jogo e contador de pontuação
- Visual moderno em tema gamer

## Executar

Abra o arquivo `index.html` no navegador. Não é necessário instalar dependências.
